# 🛍️ Luna Store | لونا ستور

متجر إلكتروني باللغة العربية، صُمم باستخدام HTML وCSS وJavaScript، مع واجهة متجاوبة وتجربة استخدام تفاعلية.

## 📌 نبذة عن المشروع

Luna Store هو مشروع عملي لتطوير واجهة متجر إلكتروني، يهدف إلى تقديم تجربة تسوق بسيطة وسهلة الاستخدام، مع تصميم مناسب للهواتف وأجهزة الكمبيوتر.

## ✨ مميزات المشروع

- 🎨 واجهة مستخدم عصرية ومنظمة.
- 📱 تصميم متجاوب مع مختلف أحجام الشاشات.
- 🛒 عرض المنتجات داخل بطاقات منظمة.
- 🔍 البحث عن المنتجات.
- 🗂️ تصنيف المنتجات حسب الفئات.
- 🖼️ عرض صور المنتجات.
- 🎞️ شريط صور متحرك في الواجهة الرئيسية.
- 🛍️ سلة تسوق تفاعلية.
- 🔔 رسائل تنبيه عند تنفيذ بعض العمليات.
- ⚡ تفاعل ديناميكي باستخدام JavaScript.

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 📂 ملفات المشروع

- `index.html` — هيكل صفحات المتجر.
- `style.css` — التصميم والألوان والتجاوب مع الشاشات.
- `script.js` — الوظائف والتفاعلات البرمجية.
- `images` — ملف مخصص للصور المستخدمة في المشروع.

## 🚀 طريقة تشغيل المشروع

1. حمّل ملفات المشروع أو انسخ المستودع.
2. افتح ملف `index.html` في المتصفح.
3. استمتع بتجربة المتجر.

## 🎯 الهدف من المشروع

تطبيق المهارات المكتسبة في تطوير واجهات الويب، والتدرب على تصميم المواقع المتجاوبة، والتعامل مع عناصر الصفحة باستخدام JavaScript.

## 👩‍💻 المطوّرة

**مريم عصام الدين الأمين**

خريجة تقنية معلومات، مهتمة بتطوير الويب وبناء مشاريع عملية باستخدام تقنيات Front-End، مع مواصلة تطوير مهاراتي في Backend وقواعد البيانات.
